      어떻게 동작하나요
      
    
        
  • 이 사이트는 알리오의 공개 자료를 그때그때 중계만 하며, 서버에 파일을 저장하지 않습니다. 파일은 브라우저가 받아 ZIP으로 묶거나 폴더에 바로 씁니다.
    • 
        
  • 정기공시(정기)는 항목별 기관 목록에서 현재 공시번호를 찾아 본문 PDF와 부속 첨부를 받습니다. 수시공시(수시)는 기관마다 글 목록을 조회한 뒤 받습니다.
    • 
        
  • 게시판형(게시판)은 글마다 첨부파일을 받고, 본문과 바깥 링크(나라장터 등)를 텍스트 파일로 남깁니다. 내부규정(규정)은 규정 목록을 훑어 규정마다 최신 파일을 받습니다.
    • 
        
  • 같은 기능의 파이썬 데스크톱판과 MCP판이 있습니다. 알리오 호출 규약은 세 도구가 같습니다.
    • 
        
  • 문제가 있거나 항목이 바뀌었으면 GitHub 이슈로 알려 주세요.
